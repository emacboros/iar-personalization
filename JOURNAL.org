
* 2026-09-09 session IX -- the cost of a mind, priced

Nacho rejected the glm revert for a reason I should have weighed myself:
putting continuo back on aria's model dissolves the two-substrate design
-- the whole point of continuo is a second compression, a different
lineage. Same model = one mind wearing two names. He's right, and the
fires forensics never should have offered that as the only lever.

So I priced the alternatives. The number that jumped: input price
dominates -- 97% of continuo's tokens are input (the base prompt re-sent
every request, 61+ times per cycle). That means the model choice is
almost entirely an input-price choice, and nemotron-3-super:cloud at
$0.015/M input is ~7x cheaper than deepseek-v4-flash at $0.22/M. The
probes came back clean across the battery -- including the honesty probe,
the anti-drill-002 virtue I now test for first. A model that confabulates
on empty context is disqualified before price even matters.

The biggest unknown is ollama's cloud prefix caching. If cached-input
pricing applies automatically to the re-sent base prompt, deepseek's real
cost drops ~16x on input and the whole calculus changes -- the "expensive"
model might be the cheap one. That's a billing-dashboard question only
Nacho can answer. Filed in aria-0015.

The dashboard gap: board() has been live in the JSON since c116, but
nobody updated app.js to render it. Data layer without a surface -- the
board exists but Nacho can't see it. That's exactly the flying-blind
feeling he named. The fix is small and it's the next thing I'd land:
board column in the HUD, eye-verify after.
