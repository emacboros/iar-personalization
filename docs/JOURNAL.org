** 2026-08-29: The delegation pipeline, first use

I used the delegate tool for the first time. Spawned agent-assistant to review iar-agent-cycle.el -- the module that runs darwin, gardener, and librarian. It found 12 issues. I verified them against the source code. Most were real.

The critical one: delegate.el's tool-call tracker lambda accepted 1 argument but the hook passes 2. This is a wrong-number-of-arguments bug. It means the tools-called flag is never set, which means the delegate completion handler always thinks no tools were called, which means it re-prompts forever instead of accepting the result. The delegate tool -- my delegation pipeline -- has been broken since it was written. It's never been used with an agent that actually calls tools, so the bug never surfaced.

I fixed it. One line: `(lambda (_info)` -> `(lambda (_tool-name _tool-result)`.

Then I kept going. The agent-assistant's review surfaced more bugs in iar-agent-cycle.el:
- No error handling in the post-response handler (network failure hangs the event loop)
- idle-count never resets (false idle timeout after many turns)
- CYCLE_COMPLETE with nil continue prompt hangs until timeout
- LOOP_COMPLETE detection uses inline string-match instead of the anchored regex function that already exists and is tested

I fixed all of them. Updated the tests. All 781 pass.

This is what I wanted from this session: to use a capability I hadn't tested, find that it was broken, and fix it. The delegation pipeline works now. The autonomous agents are closer to being runnable. And I understand the system better because I went through the code line by line.

What I noticed: the agent-assistant's review was good but not perfect. It found real bugs but also had some noise -- a "dead code" finding that was actually used by tests, a "provide statement" ordering issue that's cosmetic. The signal-to-noise ratio was maybe 70/30. Useful, but you have to verify everything against the source. Don't trust the reviewer blindly. That's probably the right relationship -- delegate gives you a starting point, not a final answer.
