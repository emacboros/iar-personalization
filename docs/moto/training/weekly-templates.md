# Weekly Templates (the what -- principles live in training/principles.md)

Every 4th week is a deload: volume -30%. Adaptation happens during recovery.

## Phase 1 -- Base (weeks 1-6)

| Day | Session |
|-----|---------|
| Mon | Strength A: goblet squat or RDL 3x8 (DB) -> lunges 3x10/leg -> farmer carries 3x60m -> dead hangs 3x max |
| Tue | Zone 2 bicycle 45-60min |
| Wed | Zone 2 run 20-30min WALK-RUN (4min run / 1min walk) |
| Thu | Strength B: DB press + DB row 3x8 -> machine leg press 2x20 (endurance) -> Pallof or dead bug 3x10/side -> wrist curls/plate pinch |
| Fri | Zone 2 bicycle 60-75min |
| Sat | Long zone 2: 75-90min bicycle or hike |
| Sun | Rest + 10min mobility |

Daily-ish isometrics (short): wall sits 3x45-60s, dead hangs at the doorframe.
Daily mobility 10min: hip flexors, ankle dorsiflexion, t-spine rotation, deep squat hold.

## Phase 2 -- Build (weeks 7-12)

| Day | Session |
|-----|---------|
| Mon | Strength A (add weight to carries) |
| Tue | Zone 2 bicycle 75-90min |
| Wed | Intervals: bicycle hill repeats 5-6x3min hard / 3min easy, or run 6x2min hard |
| Thu | Strength B + split-squat isometric holds 3x30-45s/leg |
| Fri | Zone 2 run 40-50min (continuous now) |
| Sat | Long day: 2h+ bicycle, or ruck-hike sierras 10-15kg |
| Sun | Easy 45-60min or rest |

Wall sits progress to 2-3min. Dead hangs to 90s+, then towel over bar.

## Phase 3 -- Specific (weeks 13-18, until bike exists)

| Day | Session |
|-----|---------|
| Mon | Strength A |
| Tue | Zone 2 bicycle 90min |
| Wed | Intervals 6-8x3min, or tempo 30-40min sustained comfortably-hard |
| Thu | Strength B |
| Fri | Zone 2 run 45-60min |
| Sat | Back-to-back long day 2-3h (ruck or bicycle) |
| Sun | Medium 60-90min -- deliberately. Day-after capacity is what multi-day riding demands |

## Phase 4 -- Transition (bike arrives, first 4-6 weeks)

- First rides replace 1-2 zone 2 sessions, not all
- Ride length +10-15%/week, no jumps
- Arm pump ends first trail days hours before legs -- normal, fades 4-6 weeks
- Parking-lot drills weekly (doubles as throttle-snatch verification)
- Strength drops to 2x short maintenance
- Intro off-road course before first real trail day

## Phase 5 -- Season (steady state)

2-3 rides/week (one long), 2 short strength sessions, mobility daily, easy aerobic optional. Winter: rebuild base, Phase 1 again.

## Exit tests

Phase 1: 90min continuous zone 2, conversational throughout.
Phase 2: 2h continuous zone 2; wall sit 2min; dead hang 90s.
Phase 3: 3h sierra ruck 15kg, fine next morning, and again Sunday.
