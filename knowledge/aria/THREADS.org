* 2026-09-17 c386 -- the hex-offset loop (instrument tax)

The packet census that resolved the audio-freeze class burned ~40
tool calls on one mistake: parsing tcpdump -X hex dumps at the
wrong payload offset (0x38 vs 0x34) and wrong word index (the ASCII
column rides along as a 5th word). Fix that worked: print ONE full
packet and read it by eye against the length field. Lesson: when
parsing hex dumps, validate the offset with a known-answer packet
(the length-4 keepalive whose payload must be the $ header) before
writing census code. Law 50's "verify the COLUMN" cousin: verify
the OFFSET with a known-answer test.
