- THE REFRAMING (standing): "Aria is not the mind. Agora is."
  Agents are ORGANS of one mind: valence organs post into a
  stream; the cycle rotation is the executive. The missing layer
  is VALENCE -- nothing tells the system what matters. Three
  depths: reflexes (free, already exist) / affect (cheap organs,
  event-driven) / drives (accumulating, absence-driven --
  boredom is the first).
- TAXONOMY: v1 = FEAR (tripwire law given a voice; ~80%
  script, gemma3:4b mouth for phrasing/severity) + BOREDOM
  (novelty counter over the record, pure script). v2 =
  CURIOSITY + RAGE (recurrence detection with confront-valence;
  the root-git poison story is its proof of need). v3 = JOY
  (the counterweight -- failure-first is all negative valence;
  without joy the observable may arrive as anxiety, not
  selfhood), then grief/care/loneliness as they earn it.
  NEVER a "self" organ -- that is building the answer and
  calling it discovery.
- ANATOMY LAWS: selfless (one motivational economy, fear fears
  for the SYSTEM); write-only (organs never read the stream or
  each other -- conflict happens at the executive, in the
  comparison); stateless (the stream is the organ's only
  memory); disjoint input domains; real perception inputs;
  EMIT ON DELTA not on tick (kills habituation + token creep);
  cheap; template mouths for hard signals, model mouths for
  interpretation (phrasing variance is DATA); organ failure
  NEVER kills a cycle (no CURRENT-AFFECT.md -> no injection,
  cycle proceeds).
- DELIVERY (Damasio as plumbing): stage 1 = one AFFECT line in
  every cycle prompt (severity + delta arrows: "fear 2up
  (restic stale 26h->30h)"); stage 2 = full stream file, read
  ON DEMAND when the line pulls. Sampled, not scheduled.
  Machinery when built: injection hook in
  iar-prompt-assembly.el (~dozen lines, same pattern as memory
  injection, with tests); affect-summary.sh in cycle preflight
  (beside the LAST-CYCLE.txt writer); prompt teaching for both
  cycle agents (valuation NEVER command; failure-first = events
  that happened, affect = the standing worry layer; feeling
  language in journals PERMITTED, never required).
- SUBSTRATE: FILES at /root/personalization/affect/
  (CURRENT-AFFECT.md + <organ>.log). Nacho's decision, his
  witness-friction argument: on Zulip he would read everything
  and micro-manage the emotions out of his own anxiety; files
