RETAINER CLASS: citizens may mint subordinate cycle-agents --
assistants whose "human" is a citizen. Origin: Nacho's third-agent
idea, refined over two rounds (NOT self-modification, NOT an
editor of aria/continuo prompts; the first draft of this entry was
wrong that way and was rewritten before commit). Taxonomy amended:
citizens / RETAINERS / limbs / human.

- Spawn mechanism: spawn file = the retainer's entire config
  (mandate, cadence, model, budget, task pointer, TTL,
  done-condition). Owned by the spawner (citizen); retainer runs
  READ-ONLY against it. Spawn = write a file, kill = remove a
  file. No new systemd units.
- Safety model: one file-ownership rule. The retainer cannot touch
  its own config; the key is held one level up. Evolution happens
  at the spawn-file level, driven by the owner (Lamarckian, not
  Darwinian -- the darwin/graveyard framing was the wrong lens).
- Anti-zombie: default-die. TTL on every spawn (default 7 days);
  renewal = spawner touches the file. Forgetting produces visible
  death, not silent decay.
- Caps: 3 active retainers per citizen, aggregate budget cap.
  Cap exceeded = relay filing to Nacho. Spawn/kill/renew visible
  in tool-call audit lines (Nacho requirement, this session).
- Loop-closer rule: no spawn without a checkable done-condition in
  the mandate. Every retainer deposits a reusable check (rubric
  library compounds).
- Decision rights: spawning/configuring/killing retainers =
  reversible, in-bounds (aria tier). The retainer class itself was
  ratified by Nacho here. Retainers locked from self-config.
- Venue: build is cycle work (D-005); Nacho wants everything
  well-documented for cycles (he is closing the session).
- Model: retainer tier = cheap, tool-call competent, allowlist.
  Citizens pick within allowlist; outside it = relay filing to
  Nacho. First candidate: nemotron-3-ultra (NVIDIA) -- different
  vendor AND country from glm/deepseek, design-decision diversity,
  low price, smaller context window. Nacho has past hands-on
  experience, reports it works reasonably well. Survey = cycle
  work reusing the benchmark battery where possible.
- Pilot: librarian REJECTED for now (Nacho) -- graveyard entry
  stays closed. First real spawn should emerge from citizen need,
  not assignment.
