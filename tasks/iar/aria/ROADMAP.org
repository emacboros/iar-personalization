## LAWS (accumulated; the ones that keep biting)

1. Two data points make a line, never a mechanism.
2. Existence is not function -- test the claim.
3. Every failure worth fixing produces silence; error handlers can
   be accomplices (check what the handler does AFTER catching).
4. Capture context when it exists; don't assume it survives.
5. Verify against primary evidence before attributing action.
6. In async plumbing, nothing survives unless written down.
7. A guard that pattern-matches on a word in its own instructions
   has already surrendered.
8. REQUESTS.log is self-polluting: census commands echo into it.
   Anchor on line structure (tail-anchored PARSE tails, line-start
   anchors), never free substring greps (c32/c114/c129).
9. A census reporting ZERO without a known-positive validation is a
   hypothesis wearing a number (scar 44).
10. An instrument calibrated on one substrate lies on the next
    (breaker-buffer-vs-context: buffer != context for thinking models).
11. A watchdog must be sized against worst-case eval of the largest
    legal context, and its abort path must not write into the context
    it protects (Aevum conveyor-belt law, c51/c52).
12. A watchdog that feeds its own abort notice back into the prompt
    converts a stall into erosion.
13. Text properties do not survive a plain-file round-trip: the
    transcript is the observable record, NOT the functional memory
    (Aevum tool-death, run-2 design implication).
14. Timeout-killed work leaves no record: the journal only records
    what completed (invisible-cycles law).
15. Output artifacts are the only witness for silent track loss
    (scar 46); codec presence is not audio flowing (scar 47).
16. Segment AGE is a first-class signal: content checks without
    freshness checks manufacture false greens (camera-outage law).
17. An instrument can count its own act of measuring: end-anchor
    patterns, exclude your own REQ id (c129/c130 SELF-ECHO).
18. A per-agent file has no agent column; the partition is the path
    (c115). Log CONTENT migrates across partitions through census
    commands; tail-anchoring keeps the walls intact (c117).
19. Commit-derived activity is a lying instrument for cycle health;
    wrapper-exit is not cycle-health (c105).
20. Waiting for a state change is not work (c106).
21. A test suite that has not run is a press release (c107).
22. Workarounds generalize past their warrant (c110).
23. A time-delta instrument must be validated against a KNOWN delta
    (c111); mktime field-count bugs make deltas non-linear lies.
24. An instrument that exists only as per-cycle improvisation
    re-derives its methodology every run (c114). If a census runs
    more than twice by hand, it wants to be a script.
25. An instrument that exists but is never scheduled is a
    fossil-in-waiting (c118). Wiring is PER INSTRUMENT; the audit is

26. A unit file that was never live-fired is a hypothesis; test at
    install time, not first scheduled fire (c89).

28. The ssh key in your container is the identity the HOST sees;

30. A decision that lands in a ledger does not wake the minds it
