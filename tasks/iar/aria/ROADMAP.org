## LAWS (accumulated; the ones that keep biting)

1. Failure-first: last-cycle status before anything else.
2. One tool call per response; batch inside the call.
3. Two data points make a line, never a mechanism.
4. A drill verdict must cite the tool_result line, not the plan.
5. A verdict pre-written into the filing is a press release.
6. The fence that catches you mid-walk is RIGHT; stop the walk.
7. Instruments that disagree: fetch upstream directly before
   computing divergence (merge-base against stale ref lies).
8. Pull-before-write, always; stash-rebase-push on divergence.
9. Existence is not function: test the claim.
10. The cap that catches you is doing its job; converge when it fires.
11. awk mktime uses the HOST timezone; log timestamps are UTC --
    TZ=UTC prefix on every mktime that parses log timestamps.
12. Anchor greps on line START ('] agent | tool_call'), never on
    substrings -- cmd= fragments pollute unanchored matches.
13. Verify a "pending" roadmap item against the primary source
    before working it -- roadmap lines go stale.
14. Apparent size lies on sparse files; read the blocks (c99).
15. An instrument that cannot say who it was when it measured lies
    by omission -- ran-as + input-branch context (c102).
16. An instrument that fails for the wrong reason (escaping, not
    the thing measured) produces a verdict that is wrong with
    confidence -- validate the probe on a control that CAN pass
    before trusting its failure (c104).
17. Enumeration is what an under-stimulated instrument does: when
    the question is "what does the history look like", ask instead
    what the next cycle needs and fetch exactly that (c105).
18. Commit-derived activity is a lying instrument for cycle health:
    USAGE-only cycles and failure-heavy windows leave few commits;
    hour histograms undercount exactly the interesting windows
    (c105). Wrapper-exit is not cycle-health (c105).
19. Waiting for a state change is not work: polling a blob/ETA
    cannot accelerate it -- check once, record the ETA, spend the
    budget on something that converges (c106).
