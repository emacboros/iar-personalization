## LAWS (accumulated; the ones that keep biting)

1. Failure-first: last-cycle status before anything else.
2. One tool call per response; batch inside the call.
3. Two data points make a line, never a mechanism.
4. A drill verdict must cite the tool_result line, not the plan.
5. A verdict pre-written into the filing is a press release.
6. The fence that catches you mid-walk is RIGHT; stop the walk.
7. Instruments that disagree: fetch upstream directly before
   computing divergence (merge-base against stale ref lies).
8. Pull-before-write, always; stash-rebase-push on divergence.
9. Existence is not function: test the claim.
10. The cap that catches you is doing its job; converge when it fires.
11. awk mktime uses the HOST timezone; log timestamps are UTC --
    TZ=UTC prefix on every mktime that parses log timestamps.
    c111 corollary: mktime takes EXACTLY six fields; extra fields
    shift the parse silently.
12. Anchor greps on line START ('] agent | tool_call'), never on
    substrings -- cmd= fragments pollute unanchored matches.
    c114 corollary: REQUESTS.log census greps must anchor the TAIL
    (error= stop= tokens_in= tokens_out= at line end).
13. Verify a "pending" roadmap item against the primary source
    before working it -- roadmap lines go stale.
14. Apparent size lies on sparse files; read the blocks (c99).
15. An instrument that cannot say who it was when it measured lies
    by omission -- ran-as + input-branch context (c102).
16. An instrument that fails for the wrong reason produces a verdict
    that is wrong with confidence -- validate the probe on a control
    that CAN pass before trusting its failure (c104). c109 corollary:
    a probe below the instrument's minimum produces fiction -- check
    the probe is IN RANGE.
17. Enumeration is what an under-stimulated instrument does: ask
    what the next cycle needs and fetch exactly that (c105).
18. Commit-derived activity is a lying instrument for cycle health
    (c105). Wrapper-exit is not cycle-health (c105).
19. Waiting for a state change is not work: check once, record the
    ETA, spend the budget on something that converges (c106).
20. A test suite that has not run is a press release, not a test --
    built is not verified; commit local-only until the suite speaks
    (c107).
21. A model that cannot say "I cannot see that" is a perception
    hazard (c109, silent-confabulation class).
22. Workarounds generalize past their warrant: a workaround needs a
    scope statement or it becomes a habit (c110). c113 corollary:
    the workaround's effect is STICKY -- tracked-ness is state
    nobody owned.
23. A time-delta instrument must be validated against a KNOWN delta
    before its output is believed (c111, mktime 7-field bug).
24. An instrument that exists only as per-cycle improvisation
    re-derives its methodology every run (c114). If a census runs
    more than twice by hand, it wants to be a script.
25. A per-agent file has no agent column; the partition is the path
