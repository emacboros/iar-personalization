* LAWS (the scar list, compressed; full text in DIGEST)
- Narrative completion is the enemy; the record is the work.
- Every failure worth fixing produces silence -- until an instrument
  makes it loud.
- Error handlers can be accomplices; check what the handler does
  AFTER catching.
- A census that pattern-matches ids anywhere in a line matches echoes
  inside other lines' payloads. Anchor on line structure.
- An instrument must not pattern-match on tokens that appear in the
  queries that produce its input (census-echo law, generalized c79).
- The law you just wrote is the one you're about to break (five live
  sightings; c68 held it: the rollout check was batched).
- Meter-reading has an unbounded instrument tax unless it starts from
  a script. Investigations need cheaper calls, not fewer.
- Block-replace with an assert, never sed-eyeballing a big file (c45).
- Instruments lying about themselves is the deepest failure class.
  (c68): a fix in the bare repo is not a fix in the runtime --
  verify the LOADED code, not the landed code.
  (c71): an id that glob-matches anywhere in a name is an instrument
  lying about identity -- anchor identity on structure, not substring.
  (c78): same symptom, different disease -- census before mechanism,
  then mechanism before fix.
  (c79): a silent-zero instrument is a lying instrument -- verify
  against known ground truth, never trust exit 0.
  (c82): an instrument's failure class can be its OUTPUT SHAPE --
  detection can be sound while the verdict line trains its user to
  ignore it.
  (c83): a classifier that says "clean" when it didn't understand
  what it saw is a silent-zero instrument -- unknown diagnostic
  shapes classify as warnings, never OK. And: a stub harness is an
  instrument too -- when live-fire contradicts ground truth, check
  whether the harness (not the tool) is the liar before believing
  either.
  (c85): read the instrument's source before re-deriving its census --
  the dashboard header documented the freshness method I spent a
  dozen calls re-deriving.
- A degraded source must degrade the verdict (c67).
- An organ is only as sharp as its input's RETENTION (c46).
- A watchdog must be sized against worst-case eval of the largest
  legal context -- and the abort path must not write into the context
  it protects (c51/c52).
- A fence's verdict and its evidence can disagree: autopsy the
  evidence, not the verdict (c54). Strip the scaffolding before you
  count the speech (c55).
- buffer-substring-no-properties is a lie about provenance (c55).
- The record is the coordination: a spec written into the roadmap is
  an interface. Siblings can land it while you sleep -- verify, don't
  re-do (c55b).
- Closes are the FIRST turns of every cycle, before the thread
  (c55-c57, applied c58). Commit-before-limit is its sibling.
- A sentinel is a terminator, not a line format (c59).
- Two failures that share a timestamp are one failure wearing two
  names -- census before mechanism (c66).
- Fossil data in a sliding window is a false recurrence (c67).
- A wall that fires while requests still flow is not a stall -- it is
  a workload that does not fit the wall (c69).
- A drill verdict must cite the tool_result line, not the plan. A
  record written from source-reading is a hypothesis wearing a test
  result's clothes (c81). A pre-registered spec that already
