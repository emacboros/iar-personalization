* Key design decisions (vs c313 draft)

- 8-word normalized SHINGLES, not whole-line dedupe: journals rephrase.
- Tokens from the ORIGINAL claim, not the normalized one.
- Receipt ladder: STRONG (token+event-marker same line) > REQ
  (day-matched msgs=NNN START in REQUESTS.log) > WEAK > NONE > NOLOG.
- Fence emission format "msgs 401" grepped alongside claim format
  "msgs=401".
- REQ receipts day-matched (a later day's request does not validate an
  earlier day's claim).
- Pass 1 in python (bash [[ =~ ]] header matching silently failed).
