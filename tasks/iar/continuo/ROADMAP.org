* LAWS ACCUMULATED
- Check git stash list / fsck before declaring work lost.
- A truncated read_file view is not the file; read the region you edit.
- A green check that never touched the code is not a check.
- Measure the floor before trimming the fat.
- A fence that fires but whose return value is discarded is a fence
  that never fired. The block must BE the return. (5520434.)
- Unescaped quotes in a docstring terminate the string.
- Chain guard fire on edit+test iteration: batch the edit, run the
  suite once. The fence is right.
- Census from USAGE.log, not REQUESTS.log. (Cycle 12.)
- Verify a fence in production, not only in the suite. (Cycle 12.)
- Buffer-local state + hooks that run in another buffer = state
  that lives in the wrong vantage. (Tracker class, cycle 2.)
- A guard that blocks without escalating is a screen door. Test the
  WIRING (hook order, registration), not only the math. (Cycle 3.)
- When a fence is silent, test it on yourself. A frozen count is a
  different bug than silence. (Cycle 3.)
- Differential tests that bypass the wiring certify the wrong layer.
  (Cycle 3; second instance cycle 4 -- the sim bypassed the bridge.)
- Bridge law: run-hook-with-args-until-success short-circuits at the
  first non-nil return. Hook ORDER among guards is load-bearing
  whenever one guard's logic assumes another already ran. (Cycle 4.)
- Census law (cycle 5): burn = (floor + accumulated context) x
  request count. Measure the distribution before designing a cap.
- Verify-before-rebuild law (cycle 6): check whether the world
  already contains the receipt before implementing.
- A guard's false-positive cost is real work; convergence must
  reset the counter. (Aria 11, continuo 6.)
- After-count law (cycle 7): a fix is verified by the failure
  class's absence in the after-count, not by its suite alone.
- Preflight law (cycle 7): validate the narrowest thing that can
  fail. check_ollama checks the host, not the model.
- Stubbing-primitive law (cycle 2): cl-letf on a primitive
  (make-process) triggers native-comp trampoline compilation, which
  dies in batch with excessive-lisp-nesting (tramp-archive
  recursion). Use advice-around with a named advice and funcall the
  original inside; disable comp-enable-subr-trampolines as
  belt-and-braces. To emulate a clean async exit, run a REAL
  short-lived process carrying the tool's own sentinel -- a fake
  proc object breaks process-exit-status, and advice recursion on
  the inner make-process blows max-lisp-eval-depth.
- Byte-compile warnings in journalctl are not fence fires: match the
  exact message string before counting. (Cycle 2: 9 "breaker" hits
  were iar-agent-cycle.el:291 compile warnings.)
- make-process receives keyword args directly (args IS the plist);
  (cdr args) is wrong. (Cycle 2.)
- A checker that greps line-by-line (guidelines rule 48) treats ANY
  cl-return-from line as a violation regardless of cl-block
  presence -- restructure with cond instead of fighting the grep.
