# Cross-Response Repetition Guard -- design (c111 finding)

## The gap

The deepseek text-only loop repeats the SAME paragraph ACROSS responses,
not within one. The existing output-runaway guard
(`iar--cycle-output-runaway-p`, 20 identical trimmed lines in ONE
response) never fires on the loop's early responses -- each carries only
5-10 repetitions (under threshold). The burn accumulates across
responses: the 21:10 cycle burned 22 requests / 471k input tokens /
74k output before the FINAL response (16712 identical lines, 65536
tokens, stop=length) where the truncated-output check fires FIRST in
the cond and ends the cycle.

So the per-response guard is the wrong granularity for this class. The
loop's signature is: the same line/paragraph appears in MANY consecutive
responses, each under the per-response threshold.

## Evidence (c111, cycle 21:10 UTC)

- 22 requests, 471503 input tokens, 74163 output, deepseek-v4-flash.
- Last response: 16712 identical "Let me think about what I can actually
  do this cycle..." lines, 65536 tokens, stop=length.
- Truncated-output guard fired (correctly) and ended the cycle.
- Earlier responses each had 5-10 repetitions -- under the 20-line
  per-response threshold, so the output-runaway guard never fired.

## Design

Track the most-repeated trimmed line across the last N responses
(N ~ 5). Maintain a hash table of line -> count, keyed by response
boundary. When a line's cumulative count across the window exceeds a
threshold (e.g. 30), fire the same recovery path as the output-runaway
guard (one recovery round-trip, then end on second fire).

This catches the loop at response ~5 instead of the final response,
saving ~17 requests of burn (~400k input tokens per occurrence).

## Notes

- The truncated-output check stays FIRST in the cond (it is the
  stronger, cheaper signal when it fires).
- The cross-response guard is a NEW check, not a replacement.
- Thresholds need tuning against real data (the 21:10 cycle's early
  responses had 5-10 reps; a window of 5 responses x 10 reps = 50
  cumulative would fire around response 5-6).
- Test: construct a synthetic multi-response sequence where each
  response has 5-10 reps of the same line (under per-response
  threshold) and assert the cross-response guard fires.
