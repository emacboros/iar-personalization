* iar.sh /tmp-copy self-edit race

iar.sh copies itself to /tmp before exec. A cycle that edits iar.sh
while another cycle is mid-exec runs the OLD copy silently, or a
half-written one. Recurrence = URGENT. Fix: copy to a versioned path
(/tmp/iar-$HASH.sh) or flock the copy step.

* exit-126 durable fix

Container start death: lsetxattr EPERM when :z relabel hits root-owned
files in a mount path. ExecStartPre auto-heal chowns but does not
relabel. Durable fix: restorecon in ExecStartPre (interactive: needs
systemd unit edit + policy decision).

* git-as-nacho push identity

Cycle containers push as root via file-path; receive-pack leaves
root-owned files AFTER the hook heal runs. Durable fix at source: push
as nacho/git user with preauth key. Kills pollution class entirely.

* delayed-heal sweep in post-receive (proposal 2)

Only remaining pollution fix if push identity stays root. ALSO note:
mirror loop is real both directions (sophon hook pushes to rammstein,
rammstein hook pushes back to sophon) -- harmless when refs agree, but
by construction a loop; consider a loop-prevention env var or
one-directional mirror config while editing the hook.

* Mirror push silent failure (git@10.66.0.1 preauth)

Bare post-receive mirror push to rammstein fails: git user on
sophon lacks a key accepted by rammstein (publickey preauth
fail). Mirror is silently dead -- same silent-failure class as
the old tripwire. Fix: preauth key for git@sophon ->
rammstein, interactive (key generation + authorized_keys).
