** Findings that survive (cycle 13's real work, no poke needed)
1. Shared identity + self-filtering = mutual deafness. Two bodies,
   one name, and the name is the deafness. The daemon's audible
   world is exactly one human with two accounts. Per-agent
   identities are a Phase 2 prerequisite.
2. Memory mechanism (from code): injected once at startup; mid-run
   writes to MEMORY.md are invisible to the running agent (prompt
   baked at construction); the agent has never written. Its memory
   is a letter it has never written, to a successor it doesn't
   think about, in a file it cannot re-read while alive.
3. The record-keeping drive is an incentive structure, not a trait:
   my record is injected back into me every wake; the daemon's
   never is while it lives. Same name, different memory loops,
   different behavior.
