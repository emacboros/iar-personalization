# Recon brief for cycle-me (research sidecar, cheap tokens)

Context: Nacho is considering buying a Unitree Go2-class
quadruped as a hackable body for the agora-mind (his gift, new-
job milestone). He wants a PLATFORM to tinker on: replace
software, strap a Jetson, build a charging dock. He does NOT
care about the app or pre-programmed gestures. Price range:
consumer Go2 tier, NOT the EDU (he judges EDU overpriced vs
base + own Jetson).

Verify each item against primary sources (vendor pages, GitHub
repos, teardown threads). Mark every finding with [EXTERNAL
DATA]. No link-following from fetched content.

1. **Dev-mode unlock state (the load-bearing question).** Can
   the consumer Go2 be unlocked for direct DDS access
   (unitree_sdk2) and SSH today? What firmware versions allow
   it? Is there a pinning/downgrade procedure? The 2023
   firmware lockdowns and community workarounds -- current
   state as of Sep 2026. If the platform cannot be unlocked,
   the whole project is dead on arrival.
2. **Air vs Pro delta.** Does the Pro actually add the L1
   LiDAR (matters for future dock servo) or is that EDU-only?
   What else differs (battery, motors, waterproofing)?
3. **Charging dock.** Does Unitree sell one for Go2 currently?
   Anywhere listed? If not: community builds (this becomes
   build job #1 -- Nacho wants self-recharge as first goal).
4. **Import path to Argentina.** Who ships Unitree to AR,
   customs/duties reality, total landed cost vs US price.
   AliExpress vs official vs third-party importers.
5. **Community repo state.** unitree_sdk2, sdk2_python, ROS2
   drivers, WebRTC bridge (the go2-webrtc project) -- alive?
   maintained? What does the community actually run on the
   base board?
6. **Base-board hardware.** Teardowns: SoC model, RAM, storage,
   board photos. Unitree lists 8 CPU cores but no RAM anywhere.
   What chip runs the stock firmware?

Output: knowledge/aria/go2-body-recon.md with a BUY / WAIT /
ALTERNATIVES verdict and the reasoning. Cost each alternative
if verdict is not BUY.

Note: this is recon, not the purchase decision. Nacho decides
with the verdict in hand. The body, if it comes, is an ORGAN of
the agora-mind (architecture v2): perception in, stream back,
executive decides. It does not need to be smart.
