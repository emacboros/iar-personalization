# Manual Steps for yoga ansible + backups

These must be done by Nacho on the actual hosts. The agent cannot do these.

## 1. Reinstall rammstein VPS

SSH keys were lost with the notebook. The VPS needs a fresh install.
After reinstall, ensure:
- SSH key auth configured (generate new keypair on yoga, add to rammstein)
- ansible_user (riemann) created with sudo
- The vault will need new WG keys for rammstein too (see step 2)

## 2. Generate new WireGuard keys for yoga (and rammstein if reinstalled)

```bash
# On each host:
wg genkey | tee /tmp/<host>.key | wg pubkey > /tmp/<host>.pub
```

Update vault:
```bash
cd ~/repos/iar-infrastructure
ansible-vault edit inventory/group_vars/all/vault.yml --ask-vault-pass
```

Update wg_private_keys and wg_public_keys for yoga (and rammstein if reinstalled).

## 3. Generate new GPG key for pass (yoga only)

```bash
gpg --full-generate-key  # RSA 4096, no expiry
gpg --list-secret-keys --keyid-format long
```

Add key ID to vault under pass_gpg_id.yoga.

## 4. Format external drive (optional -- ansible can do it)

Either format manually:
```bash
mkfs.ext4 -L backups /dev/sda1
```

Or set restic_format_local_drive: true in inventory/host_vars/yoga.yml for the
first ansible run, then set it back to false.

## 5. Create data directory

```bash
mkdir -p /home/nacho/data
```

## 6. Run ansible playbook

Test on yoga first:
```bash
cd ~/repos/iar-infrastructure
ansible-playbook playbooks/site.yml --ask-vault-pass --limit yoga
```

Then full site.yml once rammstein is back up:
```bash
ansible-playbook playbooks/site.yml --ask-vault-pass
```
